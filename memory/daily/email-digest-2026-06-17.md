### 📊 AGENTIC CODE REVIEW — HARDE DATA

*TLDR Newsletter — 16 juni*

Faros AI studie van 22.000 developers:
- Code churn: **+861%**
- Defect rate per developer: van **9% naar 54%**
- Review duur: **+441%**
- Zero-review merges: **+31%**

GitClear: **4x meer raw output voor ~12% geleverde waarde**

Conclusie: Review is nu de meest waardevolle skill in software-engineering. Code schrijven is commoditized; beoordelen is de bottleneck.
