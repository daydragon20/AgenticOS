# Framework AI — Naam en Positionering

> **Waarom** deze naam? Een framework is geen eindproduct, maar een basis waarop anderen bouwen. Atoom van [[Framework AI]].

## De analogie

| Framework | Wat anderen ermee bouwen |
|-----------|--------------------------|
| React | Applicaties |
| Unreal Engine | Games |
| AWS | Digitale infrastructuur |
| **Framework AI** | **Ondernemingen** |

## De positionering in één regel
> Het framework waarop toekomstige bedrijven gebouwd worden.

## Waarom dit strategisch klopt
- Een framework wordt **gebruikt**, niet verkocht als dienst → schaalbaar zonder mensen bij te zetten.
- Een framework creëert een **ecosysteem**: anderen bouwen erop verder, wat de moat vergroot.
- Een framework is **neutraal ten opzichte van sector**: hetzelfde fundament dient recruitment, horeca, bouw, logistiek.
